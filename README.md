## Overview

HunterPie is a companion overlay application for the Monster Hunter series that displays real-time monster health bars, part break thresholds, status ailment buildup meters, and quest information in a fully customizable HUD running alongside the game. Supporting Monster Hunter World, Iceborne, Rise, Sunbreak, and Wilds, it gives hunters the information advantage needed for efficient endgame grinding and speedrunning.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **HunterPie** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Monster Health Bars** | Real-time HP display with part break and enrage threshold indicators |
| **Status Buildup** | Poison, paralysis, sleep, and blast buildup meters with threshold warnings |
| **Quest Overlay** | Active quest objectives, remaining time, and team member stats display |
| **Customizable HUD** | Drag-and-drop widget placement with theme engine and opacity control |
